# Instituto Reviver

Este es un sistema que sirve para poder evaluar alumnos en el Instituto
Reviver. Utiliza [supabase.com ](https:/supabase.com) como base de datos y está creado en
[React](https://react.dev/) + [Vite](https://vite.dev/).

## Levantar proyecto

1.  Clone o descargue el proyecto.\

2.  Instale las dependencias en consola:

```sh
  npm i
```
3.  Implemente sus variables de entorno en un archivo `.env`, tomando
    como ejemplo el archivo `.env.template`.\

4.  En las variables puede decidir si va a ser de desarrollo o de
    producción en la variable:

        VITE_ENV=DES (desarrollo)
        VITE_ENV=PRO (producción)

5.  Ejecute el comando:


```sh
 npm run dev
```
¡Listo!
