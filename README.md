Instituto Reviver

Este es un sistema que sirve para poder evaluar alumnos en el institu reviver.
Utiliza supabase.com como base de datos y esta creado en React + Vite.

Levantar proyecto
1. Clone o descarge el proyecto.
2. Instale las dependencia en consola "npm i" .
3. Inplemente sus variables de entorno en un archivo .env, tome como ejemplo el archivo .env.template. 
4. En las variables puede decidir si va a ser de desarrollo o de produccion en la variable VITE_ENV= DES para desarrollo o PRO para producción.
5. Ejecute el comando "npm run dev". Listo!!!
